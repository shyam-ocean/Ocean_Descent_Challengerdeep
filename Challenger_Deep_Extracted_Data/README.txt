CHALLENGER DEEP EXTRACTED DATA
==============================

01_Full_Depth_CTD_Profile
-------------------------
Full-depth observational CTD data.
Depth reaches approximately 10,850 m.

Variables:
depth_m
salinity_PSU
potential_temperature_C
sigma8_kg_m3
potential_density_800dbar_kg_m3

02_Bathymetry_and_Vertical_Grid
--------------------------------
Bathymetry and model vertical grid.

03_Model_Temp_Sal_Density_Figure6
---------------------------------
Model temperature, salinity and density.
Includes pden_absolute_kg_m3.

04_Model_Temp_Sal_Density_Figure7_1
------------------------------------
Model temperature, salinity and density.
Includes pden_absolute_kg_m3.

Density note:
CTD rho8 is sigma_8, so absolute potential density
is calculated as 1000 + sigma_8.
Model pden is sigma_0, so absolute potential density
is calculated as 1000 + pden.
